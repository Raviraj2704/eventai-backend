# EventAI - Intelligent Event Management Platform

An AI-powered event management platform with intelligent session recommendations, 
professional networking, and real-time engagement.

## Features
- User registration and authentication
- Event and session browsing
- AI-powered session recommendations
- Professional networking
- Session ratings and reviews
- Real-time messaging
- Mobile-responsive design

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: FastAPI + Python
- Database: PostgreSQL
- Deployment: Vercel + Render
